# 🎤 AI KTV 双声道伴唱分割器 (Karaoke Splitter)

一款专门为 Windows 电脑打造的**音视频智能分离与 KTV 双声道伴唱制作工具**。

你可以直接把任何视频丢进去，软件利用深度学习 AI 模型（Demucs），自动把音频分割并重组为**行业标准的 KTV 双声道立体声**：
- 🎧 **左声道 (Left Channel)**：原装的声音 (Original Audio / 原唱，保留完整无损原音频)
- 🎧 **右声道 (Right Channel)**：背景音乐罢了 (纯伴奏 / Music，消除原声)
- 🎬 **合成视频格式**：标准高清 MP4 视频

---

## ✨ 为什么使用【左原声 + 右伴奏】KTV 双声道？

在绝大多数专业 KTV 点歌机、车载播放器、以及播放软件（如 PotPlayer、VLC）中：
1. **原唱模式**：播放左声道，即可听到原汁原味、100% 高品质的**原装完整声音**（原唱+背景音乐无任何AI数字失真）；
2. **伴唱/消音模式**：切换为右声道，就变成了纯粹的**背景伴奏音乐**，方便麦克风欢唱；
3. **练歌模式**：戴耳机时，左耳听歌手原唱，右耳听纯背景音乐，音准一清二楚！

## 🚀 使用方法

### 方式一：Web 网页端启动 (支持部署到 Streamlit Cloud 或服务器)
无需打开桌面 GUI，通过浏览器即可在手机、电脑等任意设备使用：
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```
> 如果部署到 **Streamlit Community Cloud**，平台会自动读取 `packages.txt` 和 `requirements.txt` 配置环境，直接一键上线！

---

### 方式二：Windows 本地桌面客户端
1. **双击启动**：
   - 双击 **`Run_Karaoke.bat`** 或 **`Run_Silent.vbs`**。
2. **选择视频**：
   - 点击 **选择文件** 载入你的视频（支持 MP4, MKV, MOV, FLV, AVI, WEBM 等）。
3. **一键制作**：
   - 点击 **🚀 一键分割导出 KTV 双声道 MP4 (左原声 右背景音乐)**。
   - 等待 AI 自动完成声音剥离与双声道重组。
4. **获取成果**：
   - 制作完成后点击打开目录，生成的文件为：`原视频名_KTV双声道(左原声右伴奏).mp4`。
