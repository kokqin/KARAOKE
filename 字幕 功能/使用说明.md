# 🎵 拼音歌词字幕大师 (Chinese Song Subtitle & Pinyin Studio)

专为**中文歌视频**打造的一键式桌面应用程序。支持自动语音识别歌词（Whisper AI）、自动汉字注音（带声调拼音）、时间轴可视化微调、多种 KTV/教学字幕排版风格，并利用 FFmpeg 硬件加速高清无损压制导出视频！

---

## ⚡ 一键打开方式

您可以任选以下任意一种方式一键打开本软件：

1. **桌面快捷方式（最推荐）**：
   - 您的电脑桌面上已生成 **【拼音歌词字幕大师】** 图标，直接**双击桌面图标**即可极速静默打开。
2. **文件夹内一键启动**：
   - 双击当前文件夹下的 **`一键启动.bat`** 或 **`run_app.bat`**。
   - 双击 **`启动(静默无黑框).vbs`**（静默运行，不弹出黑色命令行窗口）。

## 🌟 核心功能特色

### 1. 📁 视频一键载入
- 支持 **MP4、MKV、MOV、FLV、AVI、WebM、TS** 等常见视频格式。
- 自动读取视频分辨率、时长、帧率及音频轨道信息。

### 2. 🤖 AI 智能语音识别歌词与时间轴 (Whisper)
- 内置针对中文优化的语音识别引擎，自动从歌曲音频中切分时间轴并识别出歌词。
- 提供三种识别精度模型：
  - `base`（推荐：识别迅速，平衡稳定）
  - `tiny`（极速识别）
  - `small`（高精度：适合复杂旋律与发音）
- **多途径歌词输入**：
  - 支持直接导入现成的 `.lrc` / `.srt` 歌词字幕文件（精准到毫秒）。
  - 支持手动粘贴纯歌词文本。

### 3. 🔤 智能汉字拼音注音 (Pinyin Engine)
- 自动为每句中文歌词生成对应拼音，支持带声调符号（`wǒ hé nǐ`）、数字声调（`wo3 he2 ni3`）、无声调。
- 智能过滤或规范歌词中的标点符号。
- 在线表格支持**直接双击修改任意汉字或拼音**（遇到多音字可随时自定义）。

### 4. 🎨 多种字幕排版与实时效果预览
- **双行卡拉OK学习风（推荐）**：上方拼音（如淡黄/薄荷绿，字号稍小），下方汉字（纯白粗体带黑边描边）。
- **行内并列式**：`汉字 (拼音)`。
- **纯拼音式**：专用于练唱与拼音朗读学习。
- **字体与样式**：
  - 支持系统中文黑体、微软雅黑、楷体、宋体等。
  - 自由调节拼音字号、汉字字号、描边粗细、底部位置高低。
  - 右侧提供**实时画面预览框**，所见即所得。

### 5. 🚀 高清无损压制与导出
- 基于 FFmpeg 原生 ASS 字幕滤镜硬件加速压制，字迹清晰锐利，无模糊锯齿。
- 实时显示压制进度百分比、已用时间与预计时间。
- 导出完成后可**一键直接播放**或**一键打开输出文件夹**。

## 🛠️ 项目目录结构

```
字幕 功能/
├── app.py                      # 桌面端主图形界面程序 (CustomTkinter)
├── 一键启动.bat                 # Windows 一键启动脚本
├── run_app.bat                 # 备用一键启动脚本

├── backend/
│   ├── ffmpeg_utils.py         # FFmpeg 探测、音频提取与视频压制模块
│   ├── pinyin_engine.py        # 汉字转拼音核心引擎 (带声调、排版、多音字)
│   ├── whisper_engine.py       # Whisper 语音识别与时间轴断句模块
│   ├── ass_generator.py        # ASS 高清矢量字幕生成器
│   └── lrc_parser.py           # LRC/SRT 歌词解析与导出模块
└── 使用说明.md                  # 本说明文档
```
